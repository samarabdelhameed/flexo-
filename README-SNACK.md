# 🐕 Flexo - Snack Demo Version

## ⚠️ Important Notice

This is a **DEMO VERSION** for Snack.expo.dev preview only.

### What Works in Snack Demo:
- ✅ UI/UX Design
- ✅ Navigation flow
- ✅ Lottie animations
- ✅ Basic interactions
- ✅ Layout and styling

### What Doesn't Work in Snack:
- ❌ **Camera** - Requires native device access
- ❌ **Hand Tracking** - Requires MediaPipe (not supported in Snack)
- ❌ **Voice/Audio** - Requires expo-av (not in Snack)
- ❌ **Notifications** - Requires native modules
- ❌ **Sensors** - Requires device hardware

## 🚀 To See Full Working Version:

### Clone from GitHub:
```bash
git clone https://github.com/samarabdelhameed/flexo-.git
cd flexo-
git checkout main  # Use main branch for full features
npm install
npx expo start --tunnel
```
